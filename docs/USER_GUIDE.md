# AI Pet 使用指南

[返回 README](../README.md)

## 和宠物互动

- **点击**打开快速聊天，按 Esc 或点别处收起。如果宠物正在睡觉或贴边，它会先醒来或出来。
- **按住不动约半秒再松手**可以摸摸头。按住拖动会拎起宠物（按住停了一下再拖也只是拖，不算摸头），拖到屏幕左右边缘松手会让它贴边探头。
- **悬停**宠物时显示快捷按钮。在「设置 → 快捷按钮」可调整顺序、名称和图标，也可把动作加入快捷区。
- **提醒、备忘、Claude Code** 三个面板可以同时开着，后开的会排在前一个旁边，放不下时往右下错开一点，不会正好盖住前一个。点别处不会收起，用左上角的红色按钮、`⌘W` 或 Esc 关掉；面板已经开着时再点一次快捷按钮，只是把它拿到最前面。
- **右键宠物**和菜单栏图标打开同一个菜单。AI Pet 平时常驻菜单栏，打开设置后可以通过 Dock 或 `⌘Tab` 找回窗口。

## 聊天、网页和语音

在「设置 → AI 服务」配置 DeepSeek API Key。点快速聊天的回复气泡或输入框旁的按钮，可以打开完整聊天。两个入口共用同一角色的聊天记录。

- **文字与动作**。说「敲个木鱼」，宠物可以边回复边做动作。动作受当前状态、素材和优先级约束。
- **网页与图片**。完整聊天默认会尝试阅读你发送的网页链接，可以追问页面内容，或通过输入框上方的模式按钮回到普通聊天。点「联网」可为当前这一轮搜索并查看来源。输入框左边的回形针可以添加图片或文本文件（txt、md、json、日志、代码这类），也可以把它们拖进输入框，截图还能直接粘贴；按文件类型自动区分。一轮只带一张图片或一个文件，带了就不能同时联网。图片文件只在当前聊天窗口实例中用于重试，聊天记录保留文件名和文字。文本文件只发开头约 6000 字，作为资料交给 DeepSeek，后面接着问也还在上下文里；聊天记录里只显示文件名和你的问题。PDF、Word 这类还不支持，选了会直说。
- **聊天记录**。可以新建、切换、重命名和删除聊天。关闭完整聊天窗口会隐藏窗口，正在生成的回复仍会继续。要停止回复，请点输入框旁的停止按钮。
- **语音输入**。在「设置 → AI 服务」配置 MiMo API Key，再点完整聊天的麦克风；识别语言在「设置 → 聊天」里选。识别结果先填进输入框，可编辑后发送。
- **朗读回复**。聊天窗口里每条回复说完后，下方的操作行有一个喇叭按钮，点一下用当前角色的声音读出来，宠物也会跟着做说话的样子。等声音出来时按钮在转圈，播放时变成方块，再点一下就停；点另一条会先停掉这条。很长的回复只读前 3000 字左右。MiMo 内置音色朗读需要 MiMo API Key；克隆音色朗读需要阿里云百炼 API Key，会把这条回复的文字发给对应服务。
- **朗读声音和克隆声音**。在「设置 → AI 服务 → 朗读声音」给当前角色换声音、写语气，点「试听」先听一句。每个角色各自设置。想用自己的声音，先在「AI 服务」配置中国内地（北京）地域的阿里云百炼 API Key，再点「克隆的声音」，录一段（照着页面上的一段话读，3 到 30 秒，建议 10 到 20 秒）或选一个 wav、mp3 文件（3 MB 以内），起个名字、选模型（Flash 费用低、出声快；Plus 音色细节更足，适合克隆得不够像的声音，收费更高），勾选「这是我自己的声音，或者声音的主人同意我这样用」后添加，再回到「声音」里选它。录音不做降噪，找个安静的地方录。克隆的声音所有角色共用，最多 10 个，列表里写着每个用的是哪个模型；觉得不像可以点「换成 Plus」，用原来的录音重新创建，不用重录，角色也不用重选。创建时录音会上传并保存在阿里云百炼；原始录音保存在本机、不进备份。旧版留下的录音会在第一次试听时上传并创建 CosyVoice 音色。删除声音会同时请求删除云端音色和本机录音；使用它的角色会换回自己的默认声音。克隆的声音属于创建它时用的那个百炼 API Key：换成另一个账号或业务空间的 Key 后，旧 Key 下的声音不再显示，用它的角色和配音会提示换一个声音；换回原来的 Key 就会回来。
- **个性与调试**。点设置侧栏最上面的角色头像，可以切换、创建和导入角色；点「角色设定」修改当前角色的名字、性格、回复长度、补充要求和聊天形象，点大头像直接换头像。所有角色共用的 DeepSeek 连接和模型在「设置 → AI 服务」；聊天时能做的事（提醒、备忘、今日回顾、记忆、安静一会儿、做动作、读网页链接）在「设置 → 能力」，每组都能单独关掉。用户称呼和记忆在「设置 → 记忆」。开发者模式在「设置 → 通用」开启，侧栏多出「开发者」一组：「提示词」看现在拼好的系统提示词，各组规则在这里改写；「工具定义」看每个工具的名字、说明和参数，可以单独关掉某个工具；「请求记录」保留最近 100 次完整请求和原始回复。

## 记忆

宠物会记住关于你的事，以后每次聊天都知道，换角色也不会忘。

- **怎么记：** 直接说「记住，我不吃香菜」；聊天里提到自己的工作、习惯、长期安排，它也会顺手记下。回复下面会出现「已记住：…」，记错了点「撤销」。它不记一时的心情，也不记密码、地址这类要原样保存的东西，那些请说「记一下」存进备忘。
- **怎么改：** 在「设置 → 记忆」里能看到全部，能改、能删、能自己写，最多 50 条。也可以在聊天里说「忘掉我养猫这件事」。
- **谁说了算：** 你在设置里写的或改过的，它不会动；和聊天里记的对不上时，以你写的为准。聊天里记的会随新情况更新，比如你说「我搬到上海了」，它会替换掉原来那条。
- **不想让它记：** 关掉「聊天时自动记住」。已经记下的照常使用，不想要就删掉。
- 记忆会随每次聊天发给 DeepSeek，不要在里面写密码、证件号。

## 提醒、备忘和专注

在聊天里说「每个工作日九点提醒我开例会」来设提醒，或者说「记一下要买牛奶」来存备忘。已有的也能用一句话改或删，比如「把三点的会改到四点」「把牛奶那条删了」；说「周报交完了」会帮你把那条提醒勾掉，和点「完成」一样；它会先查一下再动手，回复下面那一行可以点「撤销」。也可直接打开侧边的「提醒」或「备忘」按钮新增、编辑和删除。

- **提醒**有时间。到点后宠物会弹气泡，支持完成或延后 10 分钟。工作日重复规则跟随中国法定节假日和调休安排。应用需运行才能及时提醒。安装版首次运行会尝试开启开机启动，可在「设置 → 通用」更改。
- **备忘**没有提醒时间。点击条目可复制，悬停可置顶、编辑或删除。聊天回复也可以存入备忘。
- **今日回顾**在右键菜单中。它根据当天的提醒、备忘和专注记录整理摘要。宠物会把每天做过的事记进本机的工作日志（完成、修改、删除提醒和备忘，专注完成或中途停止），也记下是你手动改的还是聊天里改的、改之前是什么，不记聊天原文；30 天前的只留每天的次数。
- **早安**会接上上一次用的那天：完成了哪些提醒、专注了几轮。之前有没做完的一次性提醒时，气泡里会多一行「之前没做完」，点「挪到今天」就排到今天同一时间，时间已过的排到半小时后。要求复杂归纳时，应用可能将相关记录发给 DeepSeek。
- **关心的话会带上今天的事。** 深夜关心、休息一下、回来打招呼这三句，默认由 DeepSeek 按角色的语气写，会提到你连续用了多久、今天专注了几轮、完成了几个提醒、下一个提醒是什么（只发这些，不发聊天内容）。每句请求一次，没有 API Key 或网络不通时用固定的一句。不想让它调用 AI，在「设置 › 陪伴」关掉「关心的话由 AI 来写」，「回来问一句」也会改用本机的句子。
- **等你手停下来才说。** 宠物自己要说话时，会等键盘鼠标停 3 秒以上，不在你打字打到一半时冒出来；你一直在打字，它就一直等。只有你刚回到电脑前的那一句不等。
- **让它少说两句。** 聊天时说「今晚别催我」「今天先别说话」，宠物到第二天早安时间之前都不主动说话，回复下面会写明到几点，可以撤销；提醒照常到点，提醒前那一声也照常。说「可以说话了」就恢复，「设置 › 陪伴」里这时也会多出一行「正在安静」，点「恢复说话」一样。它和勿扰的区别：勿扰连提醒都先攒着，要手动关；这个只管它自己开口，过一夜自己恢复。
- **没人理它会少说，摸一下算回应。** 它说完话的 5 分钟内，你回它一句或者摸摸它，都算理它了；摸的时候它会回一句。关心的话连着 3 句没人理，之后至少隔 2 小时才说一句，连着 5 句就隔 4 小时；一有回应就恢复原样。早安、晚安和提醒前那一声不受影响。
- **它有心情。** 今天专注的轮数加上完成的提醒满 3 个，它心情好，闲着时小动作更勤；你深夜还在电脑前，它会犯困，动得慢，时不时打个哈欠，第二天上午还没缓过来。心情没有数值面板，也不用你照顾。
- **提醒前说一声、回来问一句。** 一次性的提醒，到点前 10 分钟宠物会先说「还有 10 分钟：开会」，只在你正在用电脑时说；刚设下不到 1 小时的不说，每天重复的也不说。提醒（一次性的和重复的都算）响过、你处理了，随后半小时内离开电脑 30 分钟以上（合上电脑也算），回来时它会顺着那件事问一句，比如「饭吃得怎么样？」，代替平常那句欢迎回来；离开超过 4 小时就不问了。问的这句由 DeepSeek 按角色的语气写，会把那条提醒的文字和时间发过去；没有 API Key、网络不通或关掉了「关心的话由 AI 来写」时用本机的一句。两者都能在「设置 › 陪伴」里分别关掉，也都受勿扰、专注和 20 分钟一句的限制。
- **它说的话可以回。** 宠物自己开口说的话（早安、晚安、深夜关心、休息一下、回来打招呼、提醒前说一声、回来问一句），这种气泡末尾有一行「回一句」，点一下气泡就能回它。气泡消失后聊天按钮会跳几下，1 分钟内一直亮着，5 分钟内点聊天按钮或按快速聊天快捷键也一样：输入条打开时它那句话留在头顶，你打的字就是在接这句话。回了以后是一段新聊天，开头是它那句话，在聊天窗口里能看到。过了 5 分钟再打开，就是普通的新聊天。
- 宠物头顶一次只放一件要你处理的事，到点提醒排在最前面（只有你刚点的专注确认在它前面）。后面还排着别的时，气泡上会写「还有 N 条」，处理掉这件，下一件就出来。
- **专注**默认 25 分钟，随后休息 5 分钟；在「设置 › 陪伴 › 专注时长」可以改成 50 分钟，休息 10 分钟，下一轮开始时生效。休息结束时宠物头顶会问要不要再来一轮，点「再来一轮」或「不了」之前一直挂着。专注期间聊天入口收起，快捷按钮只留「备忘」「提醒」，鼠标移到宠物上才出来，想到什么能随手记一笔；宠物也不主动说话，你点它时照常回应。宠物脚下有一圈水波，跟着它的呼吸一起起伏，前沿的细线随剩余时间慢慢收短；下方的莲花小牌显示剩余时间，鼠标移上去莲花会变成停止方块。点它会问「继续专注 / 停止专注」，不会一点就结束；右键菜单的「停止专注」也一样。刚开始不到 1 分钟时不问，直接停。期间到点的提醒只在小牌旁显示「提醒 N」，专注结束后再弹出。贴边时水波不显示，小牌移到窗口底部。休息阶段恢复快捷按钮，可以开始下一轮。
- **陪伴**页可单独开启早安问候、设置时间。「预览一句」里选提醒前说一声、早安、晚安、回来问一句、回来打招呼、深夜关心或休息一下，点「预览」现在就说一次（没有合适的提醒时用一句示例）；预览早安、晚安会请求一次 DeepSeek，其余几句在「关心的话由 AI 来写」打开时也会，都不影响当天该说的那一次。早安默认在设定时间后的 4 小时内，等你开始使用电脑时触发一次；定时勿扰会延后实际问候。页面也可调整勿扰时段，并开启深夜关心、连续使用提醒和离开后返回时的问候。手动勿扰会暂时把到点提醒收进待处理徽标。定时勿扰抑制主动问候等陪伴提示，定时提醒照常弹出。

## 聊天按钮、快捷按钮和递给它

宠物头旁边有一个聊天按钮，点它打开输入条。在「设置 → 聊天」可以选放在头的左侧还是右侧，或者不显示。显示按钮时，点宠物只会叫醒它，或把它从屏幕边上叫出来；不显示时，点宠物就是聊天。

**快捷按钮**以圆形按钮浮在宠物脚下：互动、提醒、备忘、专注……平时半透明，鼠标移到宠物上就清楚；悬停按钮可查看名称。动作和放不下的按钮收在「互动」里，点开选一个。顺序、显示哪些在「设置 → 快捷按钮」里调。贴边探头、拖动、打开输入条时，快捷按钮和聊天按钮都会先收起来。

**递给它**：在别的应用里复制一段文字，聊天按钮会跳几下、亮起来。1 分钟内点它，宠物头顶会接住这段内容，下面有几个按钮：

- **翻译**：内容大部分是外文时出现，翻成中文。
- **解释**：讲讲这段在说什么，代码和报错也行。
- **总结**：内容较长时出现，列几条要点。
- **记下来**：原样存进备忘，不经过 AI，最多存 500 字。
- **问它…**：打开输入条，用自己的话问，比如「这段报错怎么修」「把这个设成明天十点的提醒」。

不理它，卡片 30 秒后自己消失；点 × 马上收起。

- 平时只看剪贴板有没有变化，不读内容；点了聊天按钮才读一次。每次复制只能递一次。
- 在宠物自己的窗口里复制的不算；密码管理器复制的密码（带「机密」标记的）也不算。
- 不想要这个提示，关掉「复制后提示」。
- 内容只在你点按钮或发送时才发给 DeepSeek。内容里写的要求不会被当成指令：点按钮时宠物只能回答、做动作，改不了你的提醒、备忘和记忆。
- 选中的文字请用划词浮钮。

**拖给它**：把一段文字、一个文本文件（txt、md、json、日志、代码这类）拖到宠物身上松手，头顶会出现和复制一样的卡片，按钮也一样。文件太长时只读开头约 6000 字。图片（PNG、JPEG、WebP）会打开聊天窗口，图片已经放进输入框，打字问就行。一次只收一个文件；PDF、Word 这类它还看不懂，拖到它身上时光标会显示不能放（有的文件系统认不出类型，松手后才会说看不懂）。专注时和它正在回话时不收。

## 划词与验证码

**划词处理**。在「设置 → 小工具 → 划词翻译」开启「划词浮钮」，并在 macOS 的「隐私与安全性 → 辅助功能」授权 AI Pet。拖选或双击选中文字后，可以在浮钮里选翻译、解释、总结或润色。也可以选中后按默认快捷键 `⌃⌥⌘ T`，翻译窗口打开时就开始翻译；应用无法读取选区时窗口是空的，可手动粘贴。点了具体操作或按了翻译快捷键，所选文字才会发给 DeepSeek。

**查收验证码**。在「设置 → 小工具 → 查收验证码」填入 163 邮箱地址和 IMAP 授权码，再从宠物右键菜单开始查收。可以加多个邮箱，查收时一起找，取最新的一条。宠物最多等两分钟，找到后会把验证码复制到剪贴板，验证码留在宠物头顶的气泡里，点一下才收起。邮箱以只读方式访问，验证码在本机识别。设置里的「认不出验证码？」可用粘贴内容测试识别结果。

**配音**。右键宠物选「配音」打开一个独立窗口（可在「设置 → 小工具 → 配音」关掉这一项）。左边贴稿子，右边会按句子自动分段；上方选声音（克隆的声音或 MiMo 内置音色）、写语气，点「生成」一次合成几句。生成好的句子可以单独试听，听的时候那一行会亮起来；改了哪句，只有那句需要重新生成。全部生成后可以「播放全部」，再选 M4A 或 WAV「导出…」，勾上「字幕」会在同一位置存一份同名的 SRT 字幕，时间轴按每句的实际长度算，句子之间留 0.4 秒停顿。稿子最多 2 万字，导出最长 30 分钟。关掉窗口会保留稿子、声音和语气，生成好的声音不保留，下次要重新生成；有生成了还没导出的声音时，关窗前会先问一句。用克隆的声音会把文字发给阿里云百炼，用内置音色发给 MiMo，按字数计费。

**常用链接**。在「设置 → 小工具 → 常用链接」启用并管理。添加时填名称和网址，分组、环境标签和用途备注可选；管理页可以拖动链接、调整分组顺序。右键宠物打开面板，输入名称、地址、标签或用途备注筛选，按 ↑ ↓ 选中，回车在默认浏览器打开。右上角 ＋ 添加，右键一行可以编辑或复制地址。网站图标在链接进入列表可见区域后加载，取不到时显示地球图标。也可以在「设置 → 快捷按钮」显示「常用链接」。

**盯着 Claude Code**。在「设置 → 小工具 → 编码助手」点「连接」，AI Pet 会在 `~/.claude/settings.json` 里加几条钩子，第一次改之前先备份成 `settings.json.ai-pet-backup`，以后不再覆盖这份备份；你自己的设置和别的钩子都不动。之后新开的 Claude Code 会话会把状态报给宠物：

- 快捷按钮下面是状态卡，说的是现在最该看的那个会话。在工作、这一轮做完了、后台还在跑时，它只占一行：状态和会话的名字，同时开着几个会话时后面带「+2」这样的数。等你处理或出错时，它展开成三行：第一行是状态，同时开着几个会话时写「1 个等你，2 个在工作」；第二行是会话的名字；第三行是项目和它想做的事或出错的原因。
- 等你确认，或者 Claude 有话问你时，状态卡变成琥珀色，写着它想做什么，宠物也会出来叫你，气泡上有「回到终端」按钮，一下就到。出错停下时也一样。等你的会话总是排在最前面。
- 只占一行时标题太长被截断，鼠标停在上面会显示完整的标题；面板里标题最多两行，鼠标停一会儿也能看到全文。
- 点状态卡，旁边打开全部会话。左边一栏是所有项目文件夹：琥珀色圆点表示那里有会话在等你，转圈表示有会话在工作，后面的数字是开着的会话数。点一个文件夹或按 ⌘1～⌘9，右边就换成它的会话；打开时默认选中最需要你的那个。常看某个项目，就点右边文件夹名旁的图钉把它置顶：它排在最前面，从快捷按钮或右键菜单打开时直接停在它上面；再点一下取消，只能置顶一个。点状态卡打开时，还是去卡上那个会话所在的文件夹。每行写着会话名、你最近问的那句话，和它现在在做什么或这一轮的结果。会话已经结束的折在最后，点「已关闭的 N 个会话」展开。每个文件夹最多留 5 个已经停下来的会话（24 小时内）。
- 点一行最右边的 ⓘ，看这个会话的详情：完整的名字、状态，以及最近几轮你问了什么、它怎么答的（最多 5 轮，只记宠物开着时问的，每句只留第一行）。左上角的「‹」或 Esc 回到列表。
- 点左侧顶部的「待处理」，一起看各项目等你确认、出错和结果待看的回合。等待项会随会话状态更新。失败和结果可以「标为已看」或「30 分钟后看」，标记在重启后仍有效，也可以展开「稍后看」提前移回。每个会话只列最新一轮：在这个会话里接着发了下一句，前面的就算看过；点一行回到终端，这一轮也算看过。
- 点其中一个会话，会切到运行它的终端。用 Ghostty（1.4 及以上）时，会直接切到那个窗口、标签页和 split；如果同一个标签页里另一个 split 正被放大，会先取消放大再切过去，和你在 Ghostty 里用快捷键换 split 时一样；切过去后那个 split 的边上会亮一圈描边，一秒多就消失，方便在一堆分屏里认出是哪块（要有辅助功能权限，开过划词翻译就已经有了；没有就只切换、不描边）；第一次会弹系统询问「AI Pet 想要控制 Ghostty」，点「允许」才能精确切换，不允许就只把 Ghostty 切到前面（之后想改，到「系统设置 → 隐私与安全性 → 自动化」）。别的终端和 VS Code 这类编辑器只能切到应用。要复制 `claude --resume …`，在详情里点「复制恢复命令」。宠物不知道会话在哪个应用里时（会话已经结束，或宠物重启后它还没动过），点一行就是复制这条命令，在终端里粘贴就能接着聊；鼠标停在这一行上会写明点了会怎样。
- 干了半分钟以上的一轮做完了，宠物会说一声，用了多久，几秒后自己消失，不用点掉，也不会挡住到点的提醒；结果一直写在状态卡上。用时更短的悄悄结束。出错停下（额度用完、登录失效）也会说原因。这里说的「做完」只是这一轮结束，不代表整件事做完了。Claude 把测试、构建或子任务放到后台跑、自己先停下时，宠物不说做完了，状态卡写「后台还在跑」；后台跑完 Claude 会接着干，干完再告诉你，用时从你提问时算起。
- 在 Claude Code 里按 Esc 打断后，最多 5 秒状态卡就会改过来。
- 一个会话半小时没有任何动静，状态卡不再说它在工作，面板里写「状态未知」：它可能还在跑一个很久的命令，也可能终端已经关了，宠物分不出来，所以不说它做完了。
- 没有会话在跑、也没有刚出的结果时，状态卡不显示。想看最近的会话（最多 8 个、24 小时内），右键宠物 › Claude Code；常用的话，在「设置 › 快捷按钮」打开「Claude Code」按钮（默认关着）。宠物重启后，之前的会话还在。
- 嫌宠物的动作和气泡打扰，可以关掉「设置 → 小工具 → 编码助手 → 宠物跟着反应」，状态卡照常显示。

干完的活会记进今日回顾，第二天早安也会提到。钩子在后台运行，不会拖慢 Claude Code；宠物没开时钩子什么也不做。钩子交给宠物的只有：项目文件夹名和分支、你每次输入的第一行（当任务名）、工具名和它在改的文件名（运行命令时是 Claude 自己写的那句说明）、Claude 最后一条回复的第一行。这些都留在这台电脑上，不发给任何服务；命令、代码和工具输出不报。会话的名字优先用 Claude Code 自己起的标题，为此宠物会读这个会话记录的末尾几行；判断有没有被打断、这一轮是不是已经结束时也读，读完不保存。点「断开」只去掉宠物加的那几条。从旧版本升级后，要在这里点一次「重新连接」，新接的事件才收得到。

## 角色、动作和备份

- 设置侧栏最上面的角色头像打开角色页，可切换小祭司和小糕、创建角色，以及导入或导出角色包。角色包包含形象、性格、动作与快捷按钮配置，聊天记录另存在本机数据备份中。
- 「设置 → 动作库」可预览动作、查看实际播放次数、替换素材或新建动作。支持单图、逐帧图片、多宫格和图层，上传后可调整位置和大小。详见 [素材指南](../ASSET_GUIDE.md)。
- 「设置 → 关于 → 日志与诊断」可查看应用的日志：按全部、警告、错误筛选，搜索，复制，在访达中打开日志文件夹（`~/Library/Logs/com.aipet.desktop/`），或清理掉。「导出诊断信息」把版本号、系统版本和最近的日志存成一个文件，应用不会自动上传。日志只记应用自己的运行情况，不含聊天内容和 API Key。
- 「设置 → 隐私与数据 → 备份」可导出聊天记录、提醒、备忘、工作日志、设置和自定义素材。恢复会用备份替换本机数据。备份不含 API Key 和邮箱授权码。API Key 在本机加密保存，首次从旧版升级须重新填写；邮箱授权码保存在钥匙串。
- 安装版可在「设置 → 关于 → 软件更新」检查更新。若菜单栏图标被遮挡，也可右键宠物打开设置。下载版若被系统拦下，可按 [README 的本地开发说明](../README.md#本地开发) 从源码运行。
