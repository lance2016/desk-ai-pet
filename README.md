# AI Pet

一只住在 Mac 桌面上的 2D 宠物。点一下就能聊两句，忙的时候陪你专注，到点叫你一声。

![封面插画：蓝白配色的小祭司坐在桌边，身旁放着铃铛和茶杯](./docs/images/readme-cover.jpg)

**[下载 macOS 版](https://github.com/lance2016/desk-ai-pet/releases)** · [使用指南](./docs/USER_GUIDE.md) · [本地开发](#本地开发) · [项目架构](./ARCHITECTURE.md)

## 它能做什么

| 功能 | 体验 |
| --- | --- |
| **桌面互动** | 长按摸摸头，拖到屏幕边缘看它探头。离开一会儿它会睡觉，回来继续陪你。 |
| **AI 聊天** | 用 DeepSeek 流式聊天，文字和动作可以同时出现。完整聊天支持读链接、联网搜索、图片和文本文件，MiMo 支持语音转文字。 |
| **提醒与备忘** | 说「明早九点提醒我开会」或「记一下要买牛奶」，也能说「把三点的会改到四点」「把牛奶那条删了」「周报交完了」，改错了点「撤销」。工作日提醒支持法定节假日和调休，也可以用今日回顾整理当天记录。 |
| **记忆** | 说「记住，我不吃香菜」，或者聊天里提到自己的工作、习惯，它会记下来，以后聊天都知道。在「设置 → 记忆」里能看、能改、能删，也能自己写；你写的以你为准，它不会改。 |
| **专注与陪伴** | 25 分钟专注、5 分钟休息。专注时快捷按钮和聊天入口收起，宠物不主动说话；脚下水波的前沿随剩余时间收短，下方的莲花小牌显示剩余时间，点它会问要不要结束。期间到点的提醒在小牌旁计数，专注结束后再弹出。支持可单独设置时间、在你开始使用电脑时触发的早安问候，以及晚安、连续使用提醒和定时勿扰；一次性的提醒到点前 10 分钟先说一声，提醒响过后你离开一阵再回来，它会顺着那件事问一句（重复提醒也会问）；关心的话由 AI 带着今天的事来写（可关），等你手停下来才说；说一句「今晚别催我」它就安静到明早，连着几句没人理也会自己少说；它的心情跟着你这一天走，做成了事更活泼，熬夜会打哈欠；这些主动说的话都能在设置里预览一次，也能回它：点气泡，或者 5 分钟内打开快速聊天，就是在接这句话。早安会接上昨天做了什么，没做完的提醒可以一键挪到今天。 |
| **递给它** | 在别的应用里复制一段文字，宠物旁边的聊天按钮会跳一跳；1 分钟内点它，头顶会接住这段内容，点「翻译」「解释」「总结」「记下来」，或者问它。文字和文本文件也可以直接拖到宠物身上；拖来的图片会带进聊天窗口。 |
| **桌面小工具** | 划词后翻译、解释、总结或润色，也能查收 163 邮箱的验证码。 |
| **盯着 Claude Code** | 在「设置 → 小工具 → 编码助手」连上 Claude Code 后，它干活时宠物脚下转圈；等你确认或有话问你时，宠物出来叫你；干了半分钟以上的活做完了也说一声，用时短的悄悄结束。干完的活记进今日回顾，第二天早安会提到。只报项目名、状态和工具名，不报你说的话、命令和代码。新开的 Claude Code 会话才生效。 |
| **自定义角色** | 换形象和性格，编辑多帧动作、动效及图层，导入和导出自己的角色包。 |

## 安装与上手

1. 在 [GitHub Releases](https://github.com/lance2016/desk-ai-pet/releases) 下载适合你 Mac 芯片的 ZIP。解压后把 `AI Pet.app` 拖进「应用程序」，然后打开。系统要求 **macOS 13 或更新版本**。
2. **点宠物头旁边的聊天按钮**打开快速聊天，默认全局快捷键为 `⇧⌘ Space`。按钮可以放在头的左侧或右侧，也可以关掉，关掉后点宠物就是聊天。提醒、备忘、专注和动作显示为宠物脚下的一组圆形悬浮快捷按钮，悬停可查看名称；「设置」按钮默认不显示，可在「设置 → 快捷按钮」打开。右键宠物或点击菜单栏图标，可打开完整聊天、提醒、备忘和设置。
3. 在「设置 → AI 服务」填入自己的 **DeepSeek API Key**。要用语音输入，在同一页填入 **MiMo API Key**。桌面互动、手动提醒和专注可直接使用。

更多入口可在「设置 → 功能一览」查看。已安装的用户可在「设置 → 关于 → 软件更新」检查新版。

## 数据与隐私

出了问题可以在「设置 → 关于 → 日志与诊断」查看和清理日志，或导出诊断信息。DeepSeek 和 MiMo 的 API Key 在本机加密保存。首次从钥匙串版升级需要重新填写一次，以后覆盖安装会沿用。聊天记录、提醒、备忘和工作日志保存在本机，可在「设置 → 隐私与数据 → 备份」导出或恢复。

AI 功能会把当前任务所需内容发送给对应服务。发送聊天可能附带近期对话和记忆，语音识别会把录音发给 MiMo，划词处理在点选操作后才把选中文字发给 DeepSeek。复制后只看剪贴板有没有变化，点了聊天按钮才读一次内容，点了「翻译」等按钮或发送后才发给 DeepSeek。详见[使用指南](./docs/USER_GUIDE.md)。

## 本地开发

项目使用 **Tauri 2 / Rust** 管理原生窗口和系统能力，**React / TypeScript** 编写界面和宠物逻辑，**PixiJS 8** 渲染角色。

准备 Node.js **24.x**、pnpm 9+、[Rust stable](https://rustup.rs) 和 Xcode Command Line Tools。

```bash
pnpm install
pnpm tauri dev
```

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 在浏览器调试前端，默认地址是 `http://localhost:1420` |
| `pnpm test` | 运行前端单元测试 |
| `pnpm build` | 类型检查并构建前端 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 运行 Rust 测试 |
| `pnpm tauri build --bundles app` | 构建 macOS 应用包 |
| `pnpm install:app` | 测试、打包、安装到「应用程序」并重启 AI Pet |

全屏浮层、鼠标穿透和全局快捷键需要在 macOS 应用窗口中验证。

3. 运行 `pnpm release`。脚本会打包并安装本机版本，再发布 GitHub Release 和已签名的更新包。

发布脚本与产物约定见 [scripts/release.sh](./scripts/release.sh)。
