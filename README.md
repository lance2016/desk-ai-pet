# AI Pet

一只住在 Mac 桌面上的 AI 伙伴，陪你聊天、记事、专注，也记得你的日常。

![小艾坐在书桌旁，陪伴你工作](./docs/images/readme-companion.png)

**[下载 macOS 版](https://github.com/lance2016/desk-ai-pet/releases)** · [使用指南](./docs/USER_GUIDE.md) · [本地开发](#本地开发) · [架构说明](./ARCHITECTURE.md)

## 在桌面上，陪你做事

**随时聊两句**

点宠物旁的聊天按钮，或按 `⇧⌘ Space` 打开快速聊天。想深入聊时进入完整聊天窗口：基于 DeepSeek 的流式对话支持阅读链接、联网搜索、图片和文本文件。配置 MiMo 后，可以语音输入并使用内置音色朗读；配置阿里云百炼后，可以创建 CosyVoice 克隆音色并流式朗读。

**一句话记下来**

说「明早九点提醒我开会」或「记一下要买牛奶」，宠物会分别存为提醒和备忘。提醒支持重复规则，包括中国工作日、节假日和调休；已有记录也可以通过聊天修改、完成或删除。

**一起专注，适时休息**

开始一轮 25 或 50 分钟的专注，宠物会安静陪伴，脚下的水波显示时间进度。到点提醒会先收起来，专注结束后再显示。休息、勿扰和其他陪伴行为都能在设置中调整。

**记得你，也记得今天**

宠物可以记住你主动告诉它的偏好，也能从聊天中提取信息。记忆可以查看、编辑和删除。早安、晚安、久坐和回到电脑前的问候会结合使用时间和当天记录；不想被打扰时可以让它暂时安静。

## 桌面上的小帮手

| 场景 | 可以做什么 |
| --- | --- |
| **递给它内容** | 复制文字后点聊天按钮，或拖入文字、文本文件和图片，继续翻译、解释、总结或提问。 |
| **划词处理** | 选中文字后翻译、解释、总结或润色。 |
| **查收验证码** | 配置 163 邮箱后查找最新验证码，并复制到剪贴板。 |
| **常用链接** | 按项目和环境保存常访问的网页，支持网站图标和用途备注，搜索后按回车即可打开。 |
| **配音** | 把一段稿子用克隆的声音或内置音色读出来，逐句试听、只重做改过的句子，导出 M4A 或 WAV，可带 SRT 字幕。右键宠物选「配音…」打开，关掉窗口就不占内存。 |
| **Claude Code** | 在「待处理」查看各项目等你确认、出错和有结果待看的回合，点一行回到终端。 |
| **角色和动作** | 切换或创建角色，编辑形象、性格、动作帧、动效和图层，导入或导出角色包。 |

拖动宠物、长按摸头、让它贴边探头，或者打开动作库，挑一个你喜欢的动作。快捷按钮的顺序和显示内容可以在设置里调整。

## 开始使用

1. 从 [GitHub Releases](https://github.com/lance2016/desk-ai-pet/releases) 下载对应 Mac 芯片的 ZIP，解压后将 `AI Pet.app` 拖入「应用程序」。需要 **macOS 13 或更新版本**。
2. 点宠物旁的聊天按钮，或按 `⇧⌘ Space` 开始聊天；右键宠物或点击菜单栏图标，可打开提醒、备忘、完整聊天和设置。
3. 在「设置 → AI 服务」填写自己的 **DeepSeek API Key**；语音输入和 MiMo 内置音色需要 **MiMo API Key**，克隆音色需要中国内地（北京）地域的 **阿里云百炼 API Key**。桌面互动、手动提醒和专注可以直接使用。

按住设置窗口右侧顶栏的空白处可移动窗口。子页左上角的返回按钮会显示返回目的地。

更多操作和功能限制见 [使用指南](./docs/USER_GUIDE.md)。已安装的用户可在「设置 → 关于 → 软件更新」检查新版。

## 数据与隐私

聊天记录、记忆、提醒、备忘、工作日志和设置保存在本机。DeepSeek、MiMo 和阿里云百炼的 API Key 在本机加密保存，邮箱授权码保存在系统钥匙串。可以在「设置 → 隐私与数据 → 备份」导出或恢复数据；备份不包含 API Key、邮箱授权码和克隆声音的录音。

使用 AI 功能时，相关内容会发送给对应服务：例如聊天可能包含近期对话和记忆，语音识别会向 MiMo 发送录音；创建克隆音色时，录音会上传并保存在阿里云百炼，朗读时会发送文字。Claude Code 集成在本机处理会话状态摘要，不向其他服务发送命令、代码或工具输出。详情见 [使用指南](./docs/USER_GUIDE.md)。

## 本地开发

原生窗口与系统能力使用 **Tauri 2 / Rust**，界面和宠物逻辑使用 **React / TypeScript**，角色由 **PixiJS 8** 渲染。

准备 Node.js **24.x**、pnpm 9+、[Rust stable](https://rustup.rs) 和 Xcode Command Line Tools：

```bash
pnpm install
pnpm tauri dev
```

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 在浏览器调试前端，默认地址为 `http://localhost:1420` |
| `pnpm test` | 运行前端单元测试 |
| `pnpm build` | 类型检查并构建前端 |
| `cargo test --manifest-path src-tauri/Cargo.toml` | 运行 Rust 测试 |
| `pnpm tauri build --bundles app` | 构建 macOS 应用包 |
| `pnpm install:app` | 测试、打包、安装到「应用程序」并重启 |

全屏浮层、鼠标穿透和全局快捷键需要在 macOS 应用窗口中验证。
