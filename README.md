# AI Pet

一只住在桌面上的 2D Q 版宠物，支持桌面互动和 DeepSeek 文字对话。

- 透明、无边框的桌面窗口，浮在所有窗口上方，包括全屏应用
- 只有宠物本身挡鼠标，周围的透明区域可以直接点穿
- 点一下就能跟它说话，长按摸摸它；你离开电脑它会睡着，回来它就醒
- 拖动时被拎起来，拖到屏幕左右边缘会躲到边上探头
- 空闲时自己眨眼、张望；你在用电脑它就醒着陪你，离开 5 分钟就睡着
- 动作由资源包的 `manifest.json` 定义，新增动作不用改代码
- 支持在设置中配置 DeepSeek API Key，与宠物进行流式文字对话

### 划词翻译

在「设置 → 小工具 → 划词翻译」开启「划词浮钮」后，拖选或双击选中文字，鼠标附近会出现「翻译」「解释」「总结」「润色」四个按钮和一个打开翻译窗口的图标。点哪个就在选区附近显示结果：翻译是中英互译；解释先说清这段在讲什么，再解释难懂的词，代码会说明它做什么；总结列 3～5 条要点；润色改错别字和语病，不改原意。结果卡片顶部可以直接换成另一种，不用重新选字；结果可以复制。译文显示后也可进入详情窗口并保留译文。浮钮默认关闭，开启后会检测鼠标操作并在本机读取选区；选中文字不会自动发送，只有点击按钮后才发送给 DeepSeek，不附带聊天记录和角色性格，结果不保存。浮钮会在数秒后自动收起，也可在设置中关闭。部分应用不支持读取选区，可用快捷键或手动粘贴。

在其他应用里选中文字，按默认快捷键 `⌃⌥⌘ T` 打开翻译窗口；也可以在宠物的右键菜单里选「翻译…」，或在「设置 → 小工具 → 划词翻译」打开窗口并粘贴原文，或修改、关闭快捷键。首次读取选区前，请在 macOS「系统设置 → 隐私与安全性 → 辅助功能」中允许 AI Pet。部分应用不提供选中文字，这时可以手动粘贴。选择中文或英文，点击「翻译」或按 `⌘ Enter`；结果流式显示，可以停止或复制。只有点击翻译才会把原文发送给 DeepSeek，不附带聊天记录、角色性格或聊天工具，翻译内容不保存到聊天记录。

### 查收邮箱验证码

网站把验证码发到 163 邮箱后，右键点宠物（或点菜单栏托盘图标），选「查收验证码」。宠物会找到最新的验证码，复制到剪贴板，气泡里显示「验证码 384920，已复制（发件人）」，直接粘贴就行。这个气泡（以及「没认出码」「没等到」这类结果）会一直留着，点一下才收起。邮件还没到时，宠物脚下显示「等验证码 ×」，每 2 秒查一次，最多等 2 分钟；点它就停止等待，菜单里的「停止等验证码」也一样。宠物藏起来或贴在边上时，查到验证码会出来告诉你，点掉气泡后再回到边上。

某封邮件没被认出来时，打开「设置 → 小工具 → 查收验证码」，把邮件标题和正文贴进「认不出验证码？」，边输入边告诉你结果：认出了哪个码（并在原文里标出来）、是验证码邮件但没找到码，还是不像验证码邮件。用的就是查收时的同一套规则，不需要连邮箱，内容不保存。

第一次用要在「设置 → 小工具 → 查收验证码」里填 163 邮箱地址和授权码：登录网页版 163 邮箱，在「设置 → POP3/SMTP/IMAP」开启「IMAP/SMTP 服务」，按提示拿到授权码（不是登录密码）。保存时会先登录一次，连上了才保存。授权码存在钥匙串里，不在备份中。

验证码用本机规则从邮件里认出来，不调用 AI，邮件内容不保存、不发给任何服务。收件箱以只读方式打开，不会把邮件标成已读。只看最新 10 封里 10 分钟内收到的邮件；同一封邮件的验证码只给一次，点了「重新发送」后再查收，会等新的那封。认不出的验证码邮件（比如带字母的码）会提示你去邮箱看。目前只支持 163 邮箱，连接不走系统代理。

## 启动

```bash
pnpm install
pnpm tauri dev
```

第一次启动要编译 Rust 依赖，大约一分钟。之后启动只需几秒。

只想调试界面和逻辑、不需要桌面窗口时，可以只启动前端，然后用浏览器打开 `http://localhost:1420`：

```bash
pnpm dev
```

浏览器里拖动窗口、调整大小、右键菜单都不生效，其余功能一致。

## 安装

系统要求：macOS 13 或更新版本。开机启动用到的系统接口从 macOS 13 才有。

首次克隆项目后，以及拉取的更新改动了 `package.json` 或 `pnpm-lock.yaml` 时，先同步本机依赖：

```bash
pnpm install
```

`pnpm install:app` 不会自动安装依赖；依赖同步完成后再运行：

```bash
pnpm install:app
```

它会运行测试、打包、退出正在运行的旧版、覆盖 `/Applications/AI Pet.app`，然后启动新版。改完代码想在安装版里看效果，跑这一条就行，不需要先提交。

AI Pet 平时没有 Dock 图标；打开设置窗口时会临时出现在 Dock 和 ⌘Tab 里，关掉设置就消失。退出用右键菜单、菜单栏托盘图标，或在 AI Pet 的窗口里按 ⌘Q。

## 发布

1. 把 `package.json` 里的 `version` 改成新版本号。`tauri.conf.json` 直接读这个字段，不用改第二处。
2. 在 `src/update/releaseNotes.json` 里写这一版的新功能：每条一个图标、颜色、标题和一句说明，小改动写进 `more`。没写的话测试会失败。
3. 提交并推送。
4. 运行 `pnpm release`。脚本从 `releaseNotes.json` 生成更新说明：Release 页面上是完整列表，`latest.json` 里只放各条标题连成的一行（旧版本的应用在「有新版本」那一行显示它）。想临时换成别的文字，用 `RELEASE_NOTES="这次改了什么" pnpm release`。

脚本会先检查：工作区没有未提交的改动、当前分支和远端一致、这个版本号还没发布过、更新签名私钥在本机。任何一项不满足就在打包前退出。检查通过后，它会打包（同时生成签过名的更新包）、安装到本机，然后在 `lance2016/desk-ai-pet` 以当前提交创建 `v版本号` 的标签和 Release，上传 zip、更新包和 `latest.json`。应用从这个仓库读更新，所以仓库必须保持公开。

已经装了 AI Pet 的人不用重新下载：宠物启动一分钟后和之后每天会查一次新版本，有新版本就说一句（同一个版本只说一次，勿扰时不说）；在「设置 → 关于 → 软件更新」可以手动检查、下载安装，装好后点「重启」。更新请求跟随系统代理。

更新后宠物会说一句「我更新到 x.y.z 了」，第一次打开设置时弹出这一版的「新功能」介绍，关掉后在「设置 → 关于」里还能再看。新装的人不弹。

**更新签名私钥**在 `~/.tauri/ai-pet-updater.key`（可以用环境变量 `AI_PET_UPDATER_KEY` 指定别的位置），对应的公钥写在 `tauri.conf.json` 的 `plugins.updater.pubkey`。应用只装用这把私钥签过名的更新包。私钥丢了，已经装上的用户就再也收不到更新，只能手动重装，所以要另外备份一份。它和苹果的签名证书无关。

这个包没有签名。在另一台 Mac 上下载解压后，系统会提示"已损坏"或"无法验证开发者"，需要先执行：

```bash
xattr -dr com.apple.quarantine "/Applications/AI Pet.app"
```

## 怎么玩

| 操作 | 效果 |
|---|---|
| 点一下宠物 | 脚下弹出输入框，光标已就位，直接跟它说话；点别处或按 Esc 收起 |
| 按住宠物不动 0.5 秒 | 摸摸头（按住后再拖动，照常拖走）；连着摸到第 3 次会害羞 |
| 在任何应用里按 `⇧⌘ Space` | 和点一下宠物相同，不用碰鼠标：睡着的会醒，躲在边上的会出来；再按一次或按 Esc 收起 |
| 按住拖动 | 宠物被拎起来，跟着鼠标走 |
| 拖到屏幕左边缘或右边缘松手 | 贴边躲起来，只探出半个身子 |
| 点击探头的宠物 | 从边上出来 |
| 鼠标移到宠物上 | 快捷图标在宠物两侧浮现；宠物闲着时会看一眼 |

宠物会跟着你正在做的事做动作：等回复时它在想，回复失败时一脸困惑，回复里选了动作就做出来；记下一条提醒或备忘时它记一笔，勾掉一条提醒时开心一下，快睡着前打个哈欠。在聊天窗口里聊也一样。它睡着或躲在边上时不会为这些小反应醒来或出来（发出消息会叫醒它）。
| 右键宠物 | 打开聊天窗口、提醒、备忘、今日回顾，翻译、查收验证码，摸摸头、动作（宠物两侧的喂食、敲木鱼、睡觉和自己做的动作，不用把鼠标移过去），开始/停止专注，大小（勾出当前大小）、总在最前面、勿扰、隐藏宠物，设置和退出。宠物身上、气泡、快捷按钮上右键都是这个菜单 |
| 菜单栏托盘图标 | 和右键菜单相同 |

右键菜单和托盘菜单中的“设置…”会打开独立设置窗口，样式和 macOS 系统设置一致，跟随系统深浅色。改动立即生效，保存在本机并同步到宠物窗口。

设置窗口左上角可以搜索（⌘F），设置项和功能都能搜到，也能搜别的说法，比如“置顶”找到「总在最前面」、“日报”找到「今日回顾」。上下方向键选，回车打开，打开后那一行会闪一下；Esc 清空。「设置 → 功能一览」按「和它互动」「帮你做事」「陪着你」「变成你的样子」列出宠物能做的事，每条写了怎么用，右边可以直接跳到对应的设置页。

在 AI Pet 的任一窗口里，⌘, 打开设置，⌘Q 退出，⌘W 关掉当前窗口；聊天窗口里 ⌘N 开始新聊天。删除角色、删除动作、移除 API Key、恢复默认这类不能撤销的操作，会先弹出系统确认框：回车确认，Esc 取消。

打开 macOS「减弱动态效果」后，宠物不再蹦跳、摇晃和抖动，只换姿势。

快捷图标分布在宠物两侧，鼠标移到宠物上时出现，移开约 0.7 秒后收起。宠物放大或缩小时，图标仍留在舞台预留的侧边空间，不会压住角色；贴近屏幕边缘时，图标集中到可见的一侧。默认有「聊聊天」「提醒」「备忘」「专注」四个按钮。「设置 → 快捷按钮」把所有按钮放在一个列表里（预览和宠物身上看到的一样）：开关决定显不显示，拖动左侧把手排序，点按钮名称可以改名、换图标或上传 PNG/JPG/WebP 图标，「添加动作…」把动作放进快捷区，动作行左边的减号把它移出。动作按钮显示动作自己的第一帧。在「动作库」里点动作旁边的「快捷按钮」也是同一个开关。宠物睡着时按钮照样能点，宠物会先醒过来。宠物头顶可以显示气泡，脚下可以显示状态徽标（如专注倒计时、提醒数、勿扰），点徽标打开「提醒」。资源包 `manifest.json.controls` 提供快捷按钮默认配置；设置页支持本机覆盖，不需要用户编辑 JSON。

## 已知限制

- **可点击范围比轮廓大一圈。** 大约 8 像素，为了让做动作时的宠物也点得到。
- **鼠标穿透有约 40 毫秒的延迟。** 光标刚移到宠物上的一瞬间点击，可能点到后面的窗口。
- **鼠标穿透目前只在 macOS 上验证过。**
- **托盘图标可能被刘海挡住。** 菜单栏图标太多时会出现，这时用右键菜单。
- **不能上架 Mac App Store。** 透明窗口用到了 macOS 私有 API（`macOSPrivateApi`）。
- **每个动作只有一帧。** 12 个姿势各一张图，靠程序化动效动起来，详见 `ASSET_GUIDE.md`。

设置中的「快捷按钮」可预览、排序、隐藏、添加动作和替换按钮图标；按钮收起速度在「通用」里调。

### 文字聊天

**快速聊天**是最快的开口方式：点一下宠物，或者在任何应用里按 `⇧⌘ Space`，宠物脚下就会出现输入框，光标已经在里面。回车发送，回复显示在宠物头顶的气泡里，边生成边显示，最多四行。可以接着输入继续聊；按 Esc、再按一次快捷键或点别处都会收起，键盘会还给你原来的应用。睡着或躲在屏幕边上时，点一下它会先醒来或出来，同时打开输入框。收起后回复还会停留一会儿再消失。点回复气泡或输入框右边的按钮，会在聊天窗口打开这段对话，看完整内容和历史。宠物两侧的「聊聊天」快捷图标也会打开这个输入框。

快速聊天和聊天窗口共用聊天记录：每次打开输入框都开一段新聊天，输入框收起前接着说的都算这一段。想接着以前的对话，到聊天窗口的聊天记录里切回去。快捷键可以在「设置 → AI 对话 → 快速聊天」点「录制」换成任意组合，也可以关掉。组合里必须有 ⌃ 或 ⌘：从 macOS 15 起，只用 ⌥ 或 ⌥⇧ 的全局快捷键系统不再转发，按了没反应。⌘C、⌘V、⌘Space、⌘Tab 这类系统和常用应用在用的组合录不进去。快捷键被别的应用占用时，宠物会说一句提示，换一个就行。

第一次启动、还没有配置 DeepSeek API Key 时，会自动打开设置窗口的欢迎引导：先告诉宠物怎么称呼你，再填 API Key，最后直接开始聊天。每一步都可以跳过，之后在「设置 → 角色 → 关于你」改称呼，在「设置 → AI 对话」填 Key。已经配置过 Key 的不会看到引导。

聊天窗口顶栏右侧有设置按钮。名字旁边的状态会如实显示：待命、未配置、生成中、录音中、识别中、识别失败、网络错误、Key 无效等。没有配置 Key 时，聊天窗口会显示“还差一步”的提示，发送按钮不可用，点“去设置”直接打开「AI 对话」页；配置好回到聊天窗口，提示自动消失。发送失败时会分清原因：Key 缺失或无效给出“去设置”按钮，网络问题提示检查网络后重试，余额不足和请求太频繁也会单独说明。快速聊天打开时也会先检查 Key，没有就在宠物头顶直接给出设置入口。

说「敲个木鱼」或「给我打个招呼」，宠物会边回复边做动作。动作受当前状态和素材限制，播放不了时，聊天会提示原因。

「设置 → AI 对话 → 自动阅读网页链接」默认开启，对所有角色生效。在完整聊天窗口发送网页链接，可以让宠物概括、解释或翻译网页。发送后会显示读取进度，消息里的网址和回答下方的来源都可以点开。新消息没有链接时不会重新读取网页；读完可以继续追问，或点输入框上方的模式按钮切回普通聊天。关闭自动阅读后，链接仍能在浏览器打开。阅读使用 DeepSeek Flash，只发送当前链接和问题，追问会发送这一段网页对话。过长或较早的网页可能需要重新发送链接才能追问。

查近期信息时，在完整聊天里点「联网」，输入问题再发送。它只为这一轮搜索；回答下方可以展开查看来源，点开用默认浏览器访问。要看报错截图或图表，点图片按钮、粘贴截图，或拖一张 PNG、JPG、WebP 到输入框。发送前可以预览和移除，发送时才将缩小后的图片交给 DeepSeek Flash。聊天记录只保存文件名和文字，离开当前聊天窗口实例后需重新添加图片才能再让 AI 看图。一轮可以选择搜索网页或看一张图片。

回复支持常用的 Markdown：标题、粗体、斜体、列表、行内代码和代码块。链接只显示文字，不能点击跳转。

在「设置 → AI 对话」保存自己的 DeepSeek API Key，可选测试连接并设置回复长度。同一页的「模型」选回复用的模型：内置 `deepseek-flash`（Flash，默认）和 `deepseek-pro`（Pro），也可以选「自定义」填 DeepSeek 开放平台上的其他模型名。自定义模型名会先发一条很短的消息测试，测试通过才会换，没填 API Key 时直接保存。模型对所有角色生效，聊天和问候都用它。名字和性格在「设置 → 角色」修改。想看完整对话时，从快速聊天的输入框或回复气泡打开聊天窗口。回车发送，Shift + Enter 换行，生成过程中可停止；关闭聊天窗口也会停止请求。

聊天窗口顶栏的“＋”开始一段新聊天，时钟按钮打开聊天记录，可以切回以前的对话、改名（双击标题）或删除（几秒内可以撤销）。每段对话最多保存 200 条，发给 DeepSeek 的只有当前这一段的最近 30 条。每个角色最多保留 20 段，更早的自动删除。回复旁边可以复制或存进备忘；回复停止时，已经说出来的部分会留在记录里。关掉聊天窗口不会停掉正在生成的回复，再打开就能看到；正在录音会停下。打开聊天窗口时接着最近的一段。

每段聊天用开场白作标题。「设置 → AI 对话 → 聊天记录」里的自动标题可在本机整理空格和标点。聊天窗口的标题栏显示“和<角色名>聊天”。

DeepSeek API Key 存储在 macOS 钥匙串，不写入聊天记录。用 `pnpm install:app` 打包时会自动用本机的 Apple Development 证书签名，第一次读 API Key 时选“始终允许”，之后重新部署不会再询问；没有证书时是临时签名，每次部署后都会再问一次。聊天记录保存在本机，可在聊天记录里删除；发送时会将当前消息、近期对话、称呼和性格设置、当前时间以及角色可做的动作名发送给 DeepSeek；AI 需要查看已有的提醒或备忘时，还会发送全部提醒或全部备忘；写今日回顾时，发送今天的记录。连接测试和聊天会产生服务商 API 调用，费用及服务状态以 DeepSeek 为准。API Key 的安全存储和网络请求当前支持 macOS。网络请求跟随「系统设置 → 网络」里的 HTTPS 或 SOCKS 代理，不支持自动代理配置（PAC）。

### MiMo 语音

在「设置 → 语音」保存 MiMo API Key 后，聊天输入框里的麦克风按钮可录制最长 2 分钟的语音。没有 MiMo Key 时麦克风会带一个小黄点，点它直接打开语音设置，不会先录音再报错。录音以 WAV 发送给 [MiMo ASR](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/audio/Speech-Recognition) 识别；识别文字先填入输入框供你检查和修改，再由你主动发送给 DeepSeek。朗读回复的功能暂时下线，原生端的 MiMo TTS 接口保留，之后再决定是否重新启用。Key 保存在 macOS 钥匙串，录音不保存在聊天记录。识别会向小米 MiMo 发送录音，并可能产生费用。

在设置中打开「动作库」，可查看资源包中的所有动作，按宠物什么时候做它分成「平时陪着你」「你碰它的时候」「聊天的时候」「帮你做事的时候」「小玩法」几组，每个动作下面写着它的触发时机。动作卡片和预览详情会显示实际播放次数，从本次更新起累计；旧事件不会补算，手动预览也会计入。普通动作可以让宠物播放并添加到快捷按钮；空闲动作还可以单独关闭或开启自动播放。睡眠、拖拽和贴边等状态动作由相应交互触发，不能直接播放。宠物睡着时点「播放」会先醒过来再播；正在做优先级更高的动作时，提醒和问候会等它结束后再播。

### 专注陪伴

点宠物侧边的「专注」快捷图标开始 25 分钟专注，右键菜单里也有「开始专注」。宠物会安静地陪你，旁边显示倒计时，「专注」按钮亮着，期间不会乱跑也不会睡着。时间到了它会开心地提醒你起来活动，这句话会一直留着，点一下才收起；接着是 5 分钟休息倒计时。倒计时显示在宠物脚下，带一圈随时间填满的进度环（专注紫色、休息绿色）。专注中点「专注」按钮或倒计时，气泡里会问要不要停下，并给出「继续专注」「停止专注」两个按钮；15 秒没点就当继续。休息中点倒计时，可以选「继续休息」或「开始专注」。菜单里的「停止专注」「结束休息」直接停。休息时点「再来一轮」直接开始下一轮。重启、换角色都不会打断进行中的专注；电脑睡着期间的时间不算，醒来后这一轮不计数。

### 提醒和备忘

要记下来的东西分两种，只看有没有时间：**有时间的是提醒**，到点宠物会叫你；**没有时间的是备忘**，记下来随时翻、随时复制。

在聊天里说“下午三点提醒我开会”，宠物会设一个提醒；说“每个工作日 11 点提醒我点外卖”“每天 8 点提醒我吃药”“每周五 5 点提醒我交周报”，会设成重复提醒；说“记一下要买牛奶”或“记一下 WiFi 密码是 abc123”，没有时间，就存进备忘。宠物会回一句确认，说清楚是设了提醒还是存进了备忘；AI 给的时间不完整或已经过去时，内容也会存进备忘，不会丢。确认会按 AI 的理解显示出来，比如“已设提醒：今天 15:00 · 开会”，旁边有「修改」，点了直接在「提醒」里打开这一条；存进备忘的旁边有「查看」。回复时 AI 也可能顺带让宠物做个动作。

说「查询我的提醒」或「查看我的备忘」，应用直接列出本机记录。问「明天几点开会」或「WiFi 密码是多少」这类问题时，应用才会把所查类型的记录交给 DeepSeek 整理。改时间、改内容和删除请在对应面板操作。

**提醒。** 到点宠物会从贴边处出来摇铃，头顶出现一个醒目的黄色提醒气泡“到点啦：开会”；睡着了也会醒，正在吃东西、敲木鱼也会停下来。没画摇铃图的角色借用开心的样子。提醒气泡不会自己消失，下面有两个按钮：「完成」直接勾掉这件事；「10 分钟后」先收起，10 分钟后再叫你一次（气泡写“别忘了：开会”）。在「提醒」里勾掉或删掉这件事，气泡也会跟着收起。没处理就退出了，下次打开还会再提醒。同时到点的几件事会合在一个气泡里，两件时按钮写「都完成」；超过两件时写“别忘了：A、B 等 5 件”，不带按钮，点一下打开「提醒」看全部。宠物被隐藏时，有提醒到点会自动出来；原来躲在屏幕边上的，提醒点掉后会回去接着躲。

点宠物侧边的「提醒」快捷图标打开小面板（macOS 原生毛玻璃样式，跟随系统深浅色）：顶部写好内容，时间自动选在今天下一个整点，可以改成「明天」或「日期…」再改时刻，回车添加；选的时间已经过了会提示。选「重复」可以设成工作日、每天或每周几（点选星期）。重复的提醒旁边有 ↻ 和规则，时间显示下一次什么时候响；今天勾掉只算今天做完，到下一次又会出现。标题右边是未完成的数量，做完的收在「已完成」下面；点一条可以改文字和时间（改了时间会在新时间重新提醒）；勾选完成；删除后底部会出现「撤销」，几秒内可以恢复。点面板外面它会自动收起。之前几天完成的一次性提醒会自动清掉。

**工作日按国家安排。** 设成“工作日”的提醒跟着国家法定节假日和调休走：放假那几天不响，调休补班的周末照常响。节假日数据随应用一起打包（目前到 2027 年）；缺少今年或明年的安排时，宠物每天最多联网一次去下载公开数据（npmmirror 或 jsDelivr），新一年的安排公布后就能自动用上，不需要更新应用。下载不到的年份按周一到周五算，「设置 → 小工具 → 提醒」会写出数据到哪一年。

**备忘。** 点宠物侧边的「备忘」快捷图标或右键菜单「备忘」打开小面板：

- 顶部输入框写好按回车保存，Shift+回车换行。一条最多 500 字。
- 点一条就复制到剪贴板。鼠标移上去，右边可以置顶、编辑、删除；删除后几秒内可以撤销。
- 置顶的排在最上面，其余按最近添加或修改的时间排。超过 6 条会出现搜索框。
- 聊天窗口里，鼠标移到宠物的回复上，旁边会出现「存进备忘」按钮。

提醒和备忘对所有角色通用，保存在本机。备忘最多 200 条，存满后最久没改过的未置顶备忘会被挤掉。以前版本里没有时间的待办，升级后没做完的会自动移进备忘。

### 今日回顾

右键宠物（或点菜单栏托盘图标），选「今日回顾」。聊天窗口会开一段新聊天，替你问一句“帮我回顾一下今天，写成能直接贴进日报的几条”，AI 按今天的记录写成分条文字，复制就能贴进日报。今天的记录包括：今天勾掉的提醒、今天还没处理的提醒、专注了几轮、今天新记或改过的备忘。记录里没有的事它不会编，记录太少时会请你补充；接着在聊天里说“再加上下午改了登录页的 bug”就行。

在任何聊天里说“帮我写今天的日报”“我今天都做了什么”也一样。应用按本机记录生成基础日报。用户要求复杂归纳时，才会把当天的记录交给 DeepSeek。

### 早安和晚安

每天定时勿扰结束后的 4 个小时内（默认 08:00 起），宠物第一次出现时会跟你打招呼；定时勿扰开始前半小时（默认 22:30）会跟你道晚安。它会叫醒自己、从贴边处出来，说一句话，可能提到没做完的提醒、下一个提醒，或者昨天和今天专注了几轮。每种问候一天只说一次，重启也不会重复。

配置了 DeepSeek Key 时，这句话由 DeepSeek 按角色性格来写，会把今天要处理的提醒数量、专注轮数，以及下一个和最近一个提醒的内容发给 DeepSeek；没配 Key 或请求失败时用内置句式。勿扰开着时不问候，关掉后如果还在时间段内会补上。定时勿扰关着也按这两个时间点问候。问候被频率限制挡住时，稍后会再试。

### 勿扰和定时勿扰

右键菜单里的「勿扰」可以随时开关。「设置 → 陪伴与勿扰 → 勿扰」里的「手动勿扰」也能开关它，还能设置每天的定时勿扰（默认 23:00 到次日 08:00，可以跨过午夜）。

勿扰开着时，到点的提醒不弹气泡、不做动作，只在宠物脚下显示「提醒 1」「勿扰」这样的小标签，关掉勿扰后再弹出来；点「提醒 1」打开「提醒」。定时勿扰只管宠物主动说话（问候、闲聊），你自己定了时间的提醒照常弹出。专注番茄钟不受影响。

### 切换角色

「设置 → 角色」列出所有角色，点一下就切换，宠物和聊天窗口会立即换过去。下方可以改当前角色的名字和性格，名字会显示在聊天窗口里；“恢复默认”回到角色包自带（或创建时填写）的名字和性格。

点“新建角色”，填名字和性格就能建一个自己的角色。它先借用一个内置角色的形象，之后可以在「动作库」逐张替换动作图片。动作库按场景展示图片总览，可以搜索动作、筛选已换图或待补素材；点图片就能打开大预览，左右方向键切换动作，多帧图片和图层会在预览中播放。自建角色页面会显示专属图片进度；还没画的动作显示占位、提示词和上传入口，不会拿被借用角色的形象冒充。角色列表、聊天窗口的头像和小人、「快捷按钮」页的预览和动作按钮也一样：显示换上的图，还没换的地方显示占位。只有桌面上的宠物在换完之前继续借用原来的图。

想换成自己的形象，分两步。第一步定样子：展开「素材制作说明」，复制待机图提示词，到 ChatGPT 里连同一张角色参考图一起发送，让它画出正面站立的待机图。参考图只用来照着画，可以是照片或别的画风的图；想要什么画风，改提示词里【画风】那一行。第二步画其他动作：动作卡片和预览里都可以复制该动作的提示词，已经有图片时也可以复制后重新绘制，再和待机图一起发给 ChatGPT。不用画全，没画的动作先用画好的图顶着。提示词按一个模板生成，模板可以改，改了所有动作的提示词跟着变；想画清单外的新动作，复制模板，把里面的 {动作} 换成想要的姿势，画好后在「我的动作」里新建。内置角色没有这张清单，每个动作的提示词在它的「编辑」页里复制。选好图片会打开摆位框：框就是宠物在桌面上的画面，拖动、缩放图片，让脚踩「地面」线、站直时头顶到「待机身高」虚线，所有动作的角色就一样大。按提示词画的正方形图会自动摆好，一般直接点「确定」；之后可以在编辑页点「调整位置和大小」重新摆。图片没有透明背景时编辑页会提醒，可以先在访达里右键图片，选「快速操作 → 移除背景」。自建角色可以删除，删除时它的聊天记录、自己做的动作和替换过的图片一起清掉。

「角色」页的“形象”可以给每个角色换聊天窗口里的头像和趴在输入框上的小人：默认用角色自己的形象，也可以上传 PNG、JPG、WebP 图片（会自动缩小后保存在本机）。上传后会弹出裁剪框：拖动图片调整位置，滚轮或滑块缩放，方向键微调，确定后才保存。现在用的图片随时可以点“调整”重新取景，点“恢复默认”换回角色自己的形象。小人也可以选“不显示”。

「角色」页的“导入与导出”可以把自建角色导出成一个 JSON 角色包，带上名字、性格、动作库里换过的图片、自己做的动作和快捷按钮，不带聊天记录。导入总是新增一个角色，不会覆盖已有的；如果已经有同名角色，确认时会提示，导入后自动改名为「阿橘 2」「阿橘 3」这样。

每个角色有自己的形象、名字和性格、聊天记录、快捷按钮和回复长度，互不影响。宠物大小、总在最前面、按钮收起速度、语音识别语言、勿扰和提醒备忘对所有角色通用。

升级到这个版本后，原有的聊天记录和各项设置会自动归到内置角色“小糕”名下。

### 自定义动作素材

设置 → 动作库：按动作场景浏览素材墙，可搜索名称和说明，也可筛选自己替换过的图片、沿用的图片或待补图片。点任一素材打开大预览，可用方向键切换，也能在预览中播放多帧和图片图层；这里还可让宠物做一次、调整快捷按钮和空闲自动播放。点「编辑」进入素材编辑：每个动作都可以使用单图、多张逐帧图片或横向帧图。逐帧素材可调整帧顺序、帧速和循环；单图及帧图均可选择动效、调整速度和幅度并实时预览。「随机朝左或朝右」让动作每次播放时随机左右镜像，一张图就能看向两边（「四处张望」默认打开）；只戴在一侧的发夹之类会跟着换边，不喜欢可以关掉。还可为动作添加或替换独立图片图层，调整位置、缩放、前后层级、动效，并指定图层在主图的哪些帧显示。上传图片在摆位框里摆好位置和大小后保存在本机，不改动默认资源包；可随时恢复默认。动作的触发条件、优先级及持续时间仍由框架决定。

动作库下方的「我的动作」可以新建自己的动作：起个名字，设好播放时长（0.5～10 秒），再选图片和动效；不上传图片时用角色的待机形象配动效。做好的动作可以播放、放进快捷按钮，宠物窗口不用重启就能用；编辑页里可以删除。每个角色最多 30 个。AI 聊天时不会选用这些动作，因为它看不到动作的样子。

### 开机启动和备份

「设置 → 通用 → 开机时打开」把 AI Pet 加进 macOS 的登录项，提醒只在宠物运行时才会响，所以安装版第一次启动时会自动打开这个开关；之后在设置或「系统设置 → 通用 → 登录项」里关掉都会保留。开发模式（`pnpm tauri dev`）不会自动打开，手动打开会失败，因为那时的程序不在 app 包里。

「设置 → 隐私与数据 → 备份」可以把提醒、备忘、聊天记录、所有设置和自己做的动作导出成一个 JSON 文件，也可以从这样的文件恢复。恢复会整个替换本机数据，完成后 app 自动重启；写入失败时保留原来的数据。API Key 在钥匙串里，不在备份中。
# 主动陪伴

在设置的「陪伴与勿扰」中，可以开启深夜关心、连续使用电脑后的休息建议和离开后回来打招呼，并调整关心时间和休息间隔。宠物仅在本机读取键鼠空闲时长，不读取输入内容，也不为这些关心调用 AI。专注期间不主动打扰；专注本身已有陪伴动作和完成提示。关心遵守勿扰和主动说话间隔；深夜关心可单独允许在定时勿扰期间出现，但手动勿扰始终生效。电脑休眠或采样中断后重新计时。当前电脑活动判断仅支持 macOS。

「AI 对话」设置可为每个角色填写聊天补充要求，查看聊天能力和本机生成的系统提示词、工具定义预览。补充要求随聊天请求发送给 DeepSeek，不影响早晚问候；预览不发送请求，也不包含聊天记录。

「对话规则」把系统提示词分段列出：角色和语气、日期、记提醒和备忘、查看和写日报、做动作、补充要求。其中「记提醒和备忘」「查看和写日报」「做动作」三段可以改写（每段最多 2000 字，所有角色共用），清空就是不发这一段，「恢复默认」回到应用自带的写法。改坏了规则，AI 可能不再设提醒或做动作。

打开「开发者模式」后，每次聊天实际发给 DeepSeek 的内容（系统提示词、聊天记录、工具列表，按条件查询或复杂归纳时的追加请求）和模型的原始回复都会记下来，在同一页查看、复制成 JSON。只记最近 20 条，只存在内存里，退出应用就清掉；API Key 不在其中。

动作库支持直接导入多行多列的图片：按行列自动拆分（最多 16 帧），再统一调整位置和大小。敲木鱼图片默认按 2 行 3 列拆分。编辑页的图层可添加飘字，让文字在指定帧出现并上飘淡出。
